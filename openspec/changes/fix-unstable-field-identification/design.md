# Design

## Context

See proposal.md - Why. Pengidentifikasi elemen form (label atau ID) yang ditangkap saat proses *Simpan form* sering kali mengandung teks atau ID dari internal framework yang rentan berubah-ubah.

## Goals / Non-Goals

**Goals:**
- Mengumpulkan beberapa pengenal untuk satu field sehingga apabila pengenal utama gagal, ada alternatif untuk pencarian (*fallback*).
- Menambahkan aturan pembersihan string pada teks label untuk menghapus kata-kata yang di-generate oleh Material Icons atau Quasar (misal: "arrow_drop_down").
- Membuat pola RegExp untuk mendeteksi ID acak (Quasar `f_<uuid>`, React `:r:`, Vue `v-`, Element Plus `el-id-`, HeadlessUI `headlessui-`).
- Menghasilkan laporan error pengisian field yang lebih terstruktur dan mudah dimengerti (clean name).

**Non-Goals:**
- Tidak mengubah bentuk payload nilai dropdown yang sudah diformat sebelumnya.
- Tidak berurusan dengan iframe lintas domain (cross-origin) atau Shadow DOM tertutup.

## Decisions

1. **Strategi Pengenal Multi-layer**
   *Rationale*: Karena UI framework tidak konsisten, menyimpan satu pengenal pasti akan rapuh. Kita simpan himpunan atribut. Urutan prioritas pencarian: `data-testid`/`data-cy`/`data-test` > `name` > `id` (non-auto) > `aria-label` > `label text` > `placeholder` > `contextual path`.
   *Alternatives*: Hanya menyimpan selector CSS. Namun, selector CSS sangat rentan berubah saat struktur hierarki HTML berubah sedikit saja.

2. **Deteksi ID Auto-generated**
   *Rationale*: Fungsi utilitas baru (misal `isAutoGeneratedId(id)`) akan menggunakan serangkaian pola regex.
   Pola-pola yang akan ditangkap:
   - Quasar: `^f_[0-9a-fA-F-]+$`
   - React: `^:r[a-zA-Z0-9]*:$`
   - Vuetify: `^v-[a-zA-Z0-9-]+$` atau `^input-\d+$`
   - Element Plus: `^el-id-[a-zA-Z0-9-]+$`
   - HeadlessUI: `^headlessui-[a-zA-Z0-9-]+$`
   - MUI: `^mui-\d+$`
   - Hex panjang: mengandung hash acak.

3. **Pembersihan Teks Label**
   *Rationale*: Fungsi utilitas (misal `cleanLabelText(text)`) akan menghapus teks ikon seperti `arrow_drop_down`, `arrow_drop_up`, `cancel`, `clear`, spasi berlebih, dan new line.
   *Decision*: Saat mengekstrak form, ambil label dari elemen anak yang eksplisit (misal `.q-field__label` untuk Quasar atau tag `<label>` asli) ketimbang seluruh `textContent` kontainer yang berisiko menarik nama ikon dan nilai terpilih.

4. **Kompabilitas Data Lama**
   *Rationale*: Data tersimpan yang lama tidak boleh crash. ID acak diabaikan pada proses pencarian saat load. Label lama akan dibersihkan dari "arrow_drop_down" saat pencarian. Jika tidak ketemu, laporkan error "label tidak ditemukan, simpan form ulang".

## Risks / Trade-offs

- **Risk**: Pencocokan bisa salah sasaran jika ada dua field berlabel sama dan tidak punya pengenal lain.
  → *Mitigation*: Jika pencarian dengan satu fallback menghasilkan lebih dari satu elemen (ambigu), field tersebut akan dilewati dan dilaporkan sebagai ambigu.

## Migration Plan
Tidak ada migrasi pada database persisten. Data lama dibaca lalu ditransformasi atau dibersihkan saat runtime saat melakukan "Isi form".
